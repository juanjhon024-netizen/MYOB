Letakkan file video tutorial MP4 lokal di folder ini dengan nama:
tutorial-praktik-myob.mp4

Path yang akan dibaca otomatis oleh aplikasi:
/videos/tutorial-praktik-myob.mp4

Catatan:
- Jika file belum diletakkan di folder ini, aplikasi akan menampilkan status "Video tutorial belum tersedia."
- Anda juga dapat mengunggah file video MP4 langsung melalui menu Pengelola Materi (tersimpan di IndexedDB browser perangkat masing-masing).
